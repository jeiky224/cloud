CloudSave 인증 결과 복구

팝업 연결이 끊기거나 Android WebView가 외부 브라우저를 열면 인증 페이지가 토큰을 게임 창으로 자동 전달하지 못할 수 있습니다. 이 경우에도 인증은 중단할 필요가 없습니다.

  1. Wayward 게임과 CloudSave 창을 닫지 않은 상태로 둡니다.
  2. Google 인증 페이지에서 표시되는 일회성 JSON 응답을 직접 복사합니다.
  3. 원래 게임으로 돌아가 CloudSave의 인증 응답 입력란에 붙여 넣고 적용합니다.
  4. nonce가 일치하지 않거나 요청 시간이 오래 지났다면 게임에서 Google 연결을 새로 시작합니다.

응답에는 짧은 수명의 Google 액세스 토큰이 포함됩니다. 채팅, 이메일, 공개 게시물에 붙여 넣지 마세요. 토큰을 URL에 넣거나 사이트 저장소·서버에 저장하지 않습니다.
