CloudSave 팝업 연결 복구

이 페이지는 Google 액세스 토큰과 Drive API 요청을 이 HTTPS 창 안에서만 처리합니다. 보안상 토큰을 게임 파일로 복사하거나 URL에 붙여 넣는 수동 복구 방식은 제공하지 않습니다.

  1. Wayward 게임 창을 닫지 말고 같은 브라우저에서 인증 팝업을 여세요.
  2. 팝업이 차단되면 해당 브라우저에서 팝업을 허용한 뒤 게임의 Google 연결 버튼을 다시 누르세요.
  3. 외부 브라우저로 분리되어 원래 게임 창과 통신할 수 없으면 그 인증 창은 작업을 중단합니다. 게임에서 새 연결 요청을 시작하세요.
  4. 인증 페이지의 연결 확인란을 체크한 뒤 Google 계정 연결 버튼을 누르세요.

Google 인증과 Drive 요청은 Google에 직접 전송됩니다. 인증 서버, Worker, 프록시 또는 DB는 없습니다.
